# Instruções para as imagens

Salve os arquivos de imagem nesta pasta com os nomes abaixo:

| Arquivo              | Descrição                                         |
|----------------------|---------------------------------------------------|
| mockup-kit.png       | Foto do produto completo (livro + bonuses + tablet) — PRINCIPAL |
| bonus-01.png         | Ícone dourado do checklist/documento              |
| bonus-02.png         | Ícone dourado dos erros (X vermelho ou similar)   |
| bonus-03.png         | Ícone dourado do velocímetro/performance          |
| garantia.png         | Badge circular de Garantia 7 dias                 |

Formatos aceitos: PNG (recomendado) ou JPG.
Fundo preto ou transparente funciona melhor com o tema da página.
